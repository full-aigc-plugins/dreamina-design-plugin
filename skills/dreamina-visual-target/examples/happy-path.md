# 端到端示例：无目标图时的完整获取

用户："把这张草图级页面迭代到精致，我没有参考图，你帮我定个标准。"

1. **判定路径**：已有产物（草图）+ 无目标 → 路径 B（基线精修）。
2. **请求授权**："目标生成是一次付费图像生成，以你当前草图为输入产出改进版目标，
   是否授权？" 用户确认。
3. **生成目标**：经 `dreamina_submit_image`（image2image，以当前草图为 reference），
   意图描述为"同构图的成品级渲染截图：清晰材质、完整光影、成品质感"——
   不出现"概念艺术/艺术风格"类表述。
4. **质量自检**：画幅与候选一致；逐区域可对照（导航栏、主视觉、配色、材质）。
5. **锁定**：`lock_target`，`source` 记
   `{"kind":"generated","provider":"dreamina","submit_id":"<真实ID>"}`。
6. **进入循环**：`run_first_round` → `dreamina-vision-judge` 评审 → `record_judgement`。
